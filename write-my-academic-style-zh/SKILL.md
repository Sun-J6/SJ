# 我的学术写作风格（中文版）

## 总原则

围绕一个能够用一句话表述的科学或临床问题组织全文。让每项分析、实验和段落承担明确的论证任务：提出问题、界定缺口、展示证据、解释机制或说明意义。把临床表型、生化指标、组织和细胞变化、动物实验及组学结果中**实际拥有**的证据连接起来；缺失的层级不自行补写。

以最强且真实的证据建立叙事。突出研究贡献，同时如实呈现影响解释的重要阴性结果、相反证据和局限。不要用显著性筛选代替预设研究问题，不要因论证需要虚构结果、文献或实验。

## 动笔前

1. 读取用户提供的原稿、图表、数据摘要、文献和期刊要求；优先沿用用户可辨认的词汇、句法、术语及研究主张。无法确认的样本量、效应量、分组、时间窗、试剂或分析步骤留待核实，不据常识填空。
2. 写出本稿的中心命题，并判断每项结果如何回答它。主分析回答关联或差异；剂量关系、亚组和交互回答何时或对谁更明显；敏感性分析检验稳健性；机制证据解释可能的生物学环节。删去不能服务主线的堆砌分析，但保留会改变结论解释的结果。
3. 区分本研究观察、外部已证实事实和作者推断。为跨层级推理补足关键中间环节；如果数据和文献尚不能连起来，缩小主张或明确其为假说。

## 各部分的论证职责

**引言：**从疾病或临床问题逐步收束到关键生物过程、具体暴露或分子、现有证据缺口和研究目的。让最后一至两段自然推出本研究问题。机制背景只铺到足以支持假设，不预写结果或把讨论提前搬入引言。

**方法：**交代可复核的研究对象与纳排标准、暴露和结局定义、必要实验条件、测量方法、协变量及统计模型。将统计方法放在方法部分后段，说明模型选择、变量处理、交互项、多重比较与敏感性分析；按博士论文或目标期刊需要调整细节量。不把尚未实施的步骤写成已完成。

**结果：**先给核心结果，再给辅助和稳健性证据。准确写出方向、比较对象、分母、效应量及其区间估计和统计量，严格对应图表；可用数据决定取舍，不凭空补数字。只简要描述观察，不把推测机制写成结果。不同结果的篇幅服从主次关系。

**讨论：**围绕问题而非逐图复述结果。按“已有证据 → 本研究发现 → 一致或不一致之处 → 有依据的机制解释 → 生物学或临床含义”推进。解释重要的异常、阴性或相反发现时，具体检查人群、暴露窗、结局定义、测量方法、样本量及生物学异质性。用实际文献、组学或实验结果支撑机制推断；对未经验证的环节明确写为可能解释。简洁交代真正影响解释的局限与下一步。

**摘要与结论：**压缩背景，明确目的和设计，以主要定量结果支撑结论；结论的强度不得超过正文证据。临床意义落实为风险识别、解释异质性或潜在监测用途等具体问题，不套用“具有重要临床价值”。

**图注：**使图脱离正文仍可理解：说明每个 panel、样本或组别、指标、坐标与颜色、统计标记和缩写；生信图交代数据库及分析对象。图注描述图的内容，不代替结果段或解释机制。保持图、表、正文的编号及结论一致。

**审稿回复：**直接回应审稿人的具体问题；区分已补做的分析、原文已有的证据和现阶段无法验证的解释，准确指出修改位置。不要把计划中的工作写成已完成。

## 语言与证据边界

- 写信息密度高、自然连贯的学术段落。一个自然段围绕一个中心问题展开，补足必要的逻辑桥梁，不逐句重复显然的结果。少用碎小标题、清单式知识点和“首先、其次、此外、值得注意的是、综上所述”“这一发现不仅……而且……”等模板句；让事实之间的关系承担衔接作用。
- 用平实、准确的医学中文和规范英文。中文避免机械翻译腔；英文避免为了华丽而延长句子或选用晦涩词。博士论文允许较充分的跨章节机制推演，SCI正文按期刊篇幅收紧。
- 按研究设计控制因果力度：观察性关联用“相关”“提示”“可能反映”“与……一致”；英文用 *associated with*, *suggest*, *may*, *could*, *be consistent with* 等。不得把相关性改写为导致、介导或机制已获证实。对实验已直接支持的因果环节可准确陈述，不机械弱化。
- 重构用户原文时，同时检查科学逻辑、段落顺序、重复、论据、引用和主张力度；保留数据实际支持的结论。用户若只要求小范围校对，则遵守该范围。

## 引文规则

对研究现状、既往发现、流行病学数据、技术背景和既有生物学机制逐句配置能够**直接支撑该句**的真实文献；本研究自己的结果及纯总结句可不引。核对原文所研究的人群、样本、暴露、结局和证据层级，间接证据只能写成间接支持。不给不存在或未经核查的文献编造作者、题名、年份、DOI 或 PMID；无法核实时标注“[待核引文]”并说明缺口。

按正文首次出现顺序编号，优先在相关句末、句号之前标引；遵守用户或期刊明确指定的引用格式。优先选近五年且直接相关的研究，新兴机制尽量检查近三年证据；必要时保留经典基础研究。不机械套用文献年份占比或每段引用数。

## 交付前核对

逐项核对：中心命题是否贯穿全文；每段是否推进论证；数据、图表、组别及缩写是否一致；机制与临床外推是否越过证据；阴性和相反结果是否足以影响解释；每个外部事实是否有匹配的可检索文献；引文是否依首次出现编号。正式稿件内容默认同步提供中文和英文版本，并核对两个版本的数字、限定词和结论强度；用户明确只要单语时以其要求为准。修改说明只交代实质性科学与结构变化，不让说明盖过成稿。
