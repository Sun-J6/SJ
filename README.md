# Medical Academic Writing Skills · 医学学术写作技能

Two language versions of the same writing guidance for medical manuscripts and dissertations. Each folder is an independent, installable skill.

这两个版本分别以中文和英文编写，遵循同一套医学论文写作原则；每个文件夹都可作为独立技能使用。

| Version | Skill | Main file |
| --- | --- | --- |
| 中文 | `write-my-academic-style-zh` | [`write-my-academic-style-zh/SKILL.md`](write-my-academic-style-zh/SKILL.md) |
| English | `write-my-academic-style-en` | [`write-my-academic-style-en/SKILL.md`](write-my-academic-style-en/SKILL.md) |

The guidance covers evidence-led structure, mechanistic interpretation, accurate results, causal boundaries, verified sentence-level references, bilingual consistency, and section-specific editing. Explicit manuscript data and journal instructions take priority.

规则涵盖证据链、机制解释、结果准确性、因果边界、句级真实引文、中英文一致性，以及各章节的写作职责。具体稿件数据与期刊要求优先。
